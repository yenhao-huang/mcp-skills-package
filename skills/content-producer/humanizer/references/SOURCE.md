SKILL.md adds the repository workflow and PM preservation rules. The canonical
skill name is humanizer; humanify in the user's request refers to this skill.
It is an editing guide applied by the agent, not a standalone rewriting program
or an AI-authorship detector. No runtime model service is installed here.
