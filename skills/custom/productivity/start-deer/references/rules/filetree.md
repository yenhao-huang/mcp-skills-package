# Layout

Category: skills/custom/productivity/start-deer/.

Required: SKILL.md with an ordered Workflow, STATE.md, references/rules/{env,filetree,state-rules}.md and references/template/STATE.template.md. Runtime guidance is in references/runtime.md. Executable helpers and bundled integration modules/tests belong in references/scripts/.

Do not commit runtime checkouts, virtual environments, PDFs, extracted corpora, generated reports, credentials, caches or local absolute paths. Keep report jobs outside the skill directory. No top-level scripts/ or agents/ directory is required.
