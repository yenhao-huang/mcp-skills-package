# State

For a new skill maintenance run, reset STATE.md from references/template/STATE.template.md and record scope. Set the current step in_progress before editing, then completed with concrete command/artifact evidence in the same turn. Resume existing state only when continuing that exact run.

Use pending, in_progress, completed, blocked or skipped. Never claim a step complete without evidence. Do not edit another skill's state.

Paper research jobs are independent: retain each job's job.json and results/*/status.json. Do not use the shared skill maintenance state as a research checkpoint or let parallel jobs overwrite it.
