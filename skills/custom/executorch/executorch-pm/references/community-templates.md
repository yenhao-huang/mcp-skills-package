# Community templates — drafts only

Never send these. Do not assert a diagnosis or successful reproduction without
evidence. Keep uncertain root causes tentative. Use verified names and facts.

## Offer to help

```text
Hi <name>, I’m interested in helping with this issue. I think it may be caused by <suspected root cause>. Are you currently working on a fix? If not, I’d be happy to take it on. I can reproduce <failure>, add a regression test, and then work on a fix. Thanks!
```

## PR description (personal fork only)

```markdown
## 1. Cause
<Observed failure, trigger and verified root cause.>

## 2. Algorithms
<Approach, behavioral change and relevant tradeoffs.>

## 3. File Changes
<Changed files and the purpose of each change.>

## 4. Regression Test
<Baseline failure, fixed result, exact commands and untested limitations.>

Related issue: [ExecuTorch #1234](https://redirect.github.com/pytorch/executorch/issues/1234)
```

## Notify reviewers — draft only

```text
I’ve opened PR <PR link>. Please let me know if you'd like any changes.
```

Use a redirect URL for a community PR. A draft notice does not authorize sending.
