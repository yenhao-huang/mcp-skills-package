# State

Reset STATE.md from references/template/STATE.template.md for each new run,
unless explicitly resuming that run. Mark a step in_progress before execution,
and completed only with evidence from that run. Use blocked for an actual
failure and skipped for work outside scope. Runtime query failure is not an
empty result. Keep persistent priorities separate and never reset them as
part of resetting STATE.md. Do not claim publication or scheduling without
verified remote evidence.
